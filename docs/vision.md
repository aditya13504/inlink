# InLink Vision

## Mission

Build a pseudonymous, privacy-first messaging platform for Android and iOS that combines local offline communication with global delivery through independently operated relays when connectivity exists.

## Non-goals for the first milestone

- Guaranteed communication where no physical or network path exists.
- Guaranteed always-on background mesh on every mobile OS.
- Custom cryptography.
- Voice/video calling.
- Production anonymity against a global traffic-analysis adversary.
- Emergency-service-grade availability.

## Guiding principles

1. Honest connectivity and delivery states.
2. Security before feature breadth.
3. Transport-neutral message envelopes.
4. User-controlled pseudonymous identity.
5. Community-operable infrastructure.
6. Incremental delivery with testable acceptance criteria.
